Privacy Policy

Last updated: November 23, 2026

This policy describes how White Hole Bot ("the app"), operated by the owner of the White Hole channel, handles information when it uses Google and YouTube services.

What the app does

White Hole Bot is a private tool used only by the White Hole channel owner. It uploads videos created by White Hole to White Hole's own YouTube channel using the YouTube Data API. It is not offered to the public and is not used to access anyone else's account.

Information accessed

  • An OAuth authorization token for the channel owner's own Google account, used solely to upload videos and set their title, description and privacy status.
  • No information about viewers or other YouTube users is collected, stored or shared.

Storage and security

The authorization token is stored as an encrypted secret in the owner's private infrastructure and is never published or shared with third parties. The app does not sell, rent or transfer any data.

YouTube API Services

The app uses YouTube API Services. By using it, the owner agrees to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy. Access can be revoked at any time from the Google security settings page.
